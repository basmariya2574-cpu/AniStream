# 🎌 AniStream – Modern Anime Streaming Platform

## 📖 Overview

AniStream is a modern anime streaming web application designed to provide anime fans with a clean, immersive, and user-friendly viewing experience. The platform helps users discover trending anime, explore different genres, manage watchlists, and enjoy anime content through an attractive interface inspired by leading streaming services.

This project was developed to learn modern frontend development, UI/UX design, routing, state management, and scalable application architecture.

---

## 🎯 Purpose

The purpose of AniStream is to create a centralized platform where anime enthusiasts can easily discover, organize, and enjoy their favorite anime series.

The project focuses on:

- Improving anime discovery
- Enhancing user experience
- Building a responsive streaming interface
- Learning real-world web application development

## ⚙️ How It Works

1. Users open the AniStream platform.
2. The homepage displays trending and recommended anime.
3. Users can search or browse anime by category.
4. Selecting an anime opens a detailed information page.
5. Users can add anime to watchlists or favorites.
6. Viewing progress is automatically tracked.
7. Users receive recommendations based on activity.
